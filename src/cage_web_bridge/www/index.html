③ 三种任务模式、参数与航点预览

已实飞验证的双 GPS 中点模式

A/B 作为网箱直径端点，目标为两点中点；“投喂开启时间”同时是中点停留时间，保持原有 AUTO.RTL 链路。

双 GPS 对角点正方形 + n×m 小网格

A 和 B 是大网箱的两个相对顶点，AB 是大网格对角线。程序由 AB 生成两条互相垂直且等长的边，不再把经纬度的东/北分量当作长宽。大网格沿这两条边分成 n×m，航点严格位于每个小网格中心，蛇形遍历。

无地面 A/B：数据库已审核 XY

照片或人工坐标只提供 XY；Z 完全由下方高度参数决定。

安全边界与系统关闭

网页不会 arm、不会直接发送遥控通道、不会覆盖 H12。飞行异常立刻切 POSCTL/ALTCTL 人工接管；飞机解锁时禁止停止 rosbag和整个系统。

仅在飞机已落地并确认未解锁后使用。停止后保留网页监督器，可再次启动整套系统。
