## 已实现的三种可选模式

1. **双 GPS 中点** `GPS_CENTER`
   - 保留已完成实飞的原链路。
   - GPS A/B 是圆形网箱直径端点，投喂点是两点的几何中点。

2. **双 GPS n×m 小网格** `GPS_GRID`
   - A→B 定义大网箱主轴，`m` 列沿 A→B 均分。
   - `n` 行沿 A→B 的左法向展开，总宽度由网页的“大网箱总宽度”参数给出。
   - 每个目标点是小网格的几何中心，标识为 `RxxCxx`。
   - 路径按行蛇形遍历，与原仿真网格顺序一致。
   - 安全限制：单维 1…50，总目标数不超过 200。

3. **照片 GPS 小网箱点** `PHOTO_POINTS`
   - 不要求地面 GPS A/B。
   - 严格按 V5 边界，不允许把未审核的照片 EXIF 直接变为实飞航点。
   - 仅显示并使用“DJI GPS / 网箱坐标库”中已绑定小网箱、已人工审核的活动坐标版本。
   - 只取纬经度 XY，照片的高度字段不参与规划。
   - 全部目标高度使用网页“投喂相对高度”。
   - 从 K9 当前 GPS 位置开始，使用确定性最近邻顺序规划。

## 网页实时显示

- 离线米制 2D Canvas，不依赖公网地图瓦片。
- 显示计划航线、航点序号、小网箱 ID 和无人机实时位置。
- 绿色：已完成；橙色：当前；蓝色：待执行；白色三角：无人机。
- 航点表和进度卡每秒读取 `/mission/state`、`/mission/waypoints` 与无人机 GPS 更新。
- rosbag 继续记录 `/mission/state`、`/mission/waypoints`、`/mavros/mission/reached`、GPS、投喂指令和回传。

## 网页操作顺序

1. 从 8080 启动原有 GPS + MAVROS + 航点 + 投喂系统。
2. 按原页面完成“系统状态”和“场地确认”；这两个初始化区域没有修改。
3. 在第③区选择任务模式，填写对应参数。
4. 点击“生成预览”，人工核对地图、航点表、坐标、高度、顺序和网格 ID。
5. 只有核对无误才点击“航点核对无误”。
6. 开始 rosbag，确认 `START READY: YES`。
7. 提交任务；网页不解锁。飞手用 H12 解锁，CH5/E 右档才允许请求 `AUTO.MISSION`。
8. 任何异常立即切换 `POSCTL`/`ALTCTL` 人工接管；自动任务不会抢回控制权。

## 门禁差异

- `GPS_CENTER` / `GPS_GRID`：要求 GPS A/B 健康、时间配对有效且几何有效。
- `PHOTO_POINTS`：A/B 和 A/B 几何门禁标记为 `SKIPPED`，但 FCU、K9 GPS、RC、飞控预起飞模式、真实投喂器、现场确认、人工预览确认和 rosbag 仍必须全部通过。
- 三种模式都保留 AUTO.RTL 收尾、H12 人工接管优先和“网页不自动 arm”边界。
